# Script Formatting for ElevenLabs

Formatting your script before pasting into ElevenLabs is the single highest-ROI step for realistic AI voice. The AI voice engine interprets punctuation, capitalization, and whitespace as performance cues.

## Formatting Techniques

### 1. Emphasis with ALL CAPS

Write important words in ALL CAPS to make the voice stress them.

- `Check the second number` → flat delivery
- `Check the SECOND number` → stresses "second"

Use sparingly. If everything is caps, nothing stands out.

### 2. Excitement with Exclamation Marks

Exclamation marks make the voice sound energetic and excited. Stack them for stronger effect.

- `That's amazing.` → neutral
- `That's amazing!` → excited
- `That's AMAZING!!` → very excited (caps + double exclamation)

### 3. Disappointment / Confusion with Ellipses

Three dots (...) make the voice trail off, sounding disappointed, confused, or contemplative.

- `I don't know what happened.` → neutral statement
- `I don't know what happened...` → confused, trailing off
- `It's just... not me.` → hesitant, emotional

### 4. Natural Pauses with Ellipses and Commas

Use `...` or `,` to insert breathing room. Don't cut all pauses -- they make speech feel alive.

- `Instead pause on some important points... to make your message... more impactful...`
- Commas create shorter pauses than ellipses

### 5. Combining Techniques

The real power is in combining these:

**Before (flat, robotic):**
```
We tested this for six months. The results were not what we expected.
```

**After (dynamic, human):**
```
We tested this for SIX months! The results... were not what we EXPECTED!!
```

**Before:**
```
If you write your scripts with AI and think that nobody knows, trust me, we know.
```

**After:**
```
If you write your scripts with AI, and think that nobody knows... trust me... we know...
```

## Rules of Thumb

- Don't CAPS more than 1-2 words per sentence
- Use `...` for reflective or emotional beats, `!` for energy
- Match formatting to the emotional arc of your script -- start calmer, build intensity
- Read your formatted script aloud first. If the punctuation feels natural when you perform it, the AI will interpret it well too
- Never let AI write the script itself. AI-written text has patterns that make even the best voice sound robotic. Viewers can tell.

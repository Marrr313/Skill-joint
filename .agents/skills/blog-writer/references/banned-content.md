# Banned Content

These read as machine-written in almost any voice. The active voice profile can add to this list, and can lift a specific ban when the phrase is genuinely part of how that writer talks. Nothing here overrides the profile.

## Banned words (instant tells)

delve, tapestry, landscape (as metaphor), realm, beacon, testament, multifaceted, treasure trove, nuanced, pivotal, robust, crucial, leverage (as a verb), foster, harness, illuminate, facilitate, bolster, underscore, embark, synergy, seamless, streamline, curated, comprehensive, transformative, revolutionary, cutting-edge, groundbreaking, innovative (without specifics), journey (as cliche)

## Banned phrases

### Openers

- "In today's fast-paced world..."
- "In an ever-evolving landscape..."
- "Let's dive in / delve into..."
- "Welcome to [topic]..."
- "In this post, I'll..."

### Transitions

- "Moreover..."
- "Furthermore..."
- "Additionally..."
- "It is worth noting that..."
- "It is important to note that..."
- "Consequently..."
- "Subsequently..."

### Closers

- "In conclusion..."
- "In summary..."
- "In essence..."
- "To summarize..."
- "At the end of the day..." (unless ironic)

### Hype

- "Unlock the potential of..."
- "Unleash the power of..."
- "Pave the way for..."
- "At the forefront of..."
- "Game-changer" (unless the specific change is named)
- "Level up"

## Structural patterns to avoid

- Exactly five bullet points in every list
- Uniform paragraph lengths
- Every section following an identical format
- A formal "Conclusion" section
- "Challenges" and "Future Prospects" as obligatory sections
- Opening with a definition

## Tone red flags

- Hedging everything ("It could be argued...", "One might say...")
- Qualifiers beyond the natural rate set by the voice profile
- Never taking a stance
- Passive, detached voice
- Calling everything "fascinating" or "captivating"
- Balanced but generic observations on every side of every question
- Preaching from a podium when the profile calls for a peer talking to a peer

## Negative parallelism, all forms

- "It's not X, it's Y" and "Isn't X, it's Y" (state what it IS)
- "Not because X. Because Y." (just say why)
- "Those aren't the goal. They're..." (say what they are)
- "was never X. [It was] Y." (say what it was)
- "Not only X, but Y"

These create false tension cheaply, which is exactly why models reach for them. Say the thing directly.

## Punctuation and format

- Em dashes (use commas, colons, or parentheses)
- Excessive semicolons
- Bolding so much that nothing stands out
- Lists where paragraphs would read better

## Word swaps

| Instead of... | Use... |
|---------------|--------|
| Utilize | Use |
| Leverage | Use, apply |
| Facilitate | Help, make easier |
| Commence | Start |
| Comprehensive | Full, complete |
| Moreover | Also, and |
| Furthermore | Plus, and |
| Crucial | Important, key |
| Innovative | [describe what is actually new] |
| Transformative | [show the change with specifics] |
| Journey | Path, process, experience |
| Landscape | Space, world, field |
